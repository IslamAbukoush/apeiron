# Cloud model failover

Choose **Automatic: Gemini, Groq, AnyRouter free** under Conversation and planning model. It is the default for new browser profiles. An existing saved Local or Hybrid selection is preserved; change it once to enable Automatic. The decision model and local speech/microphone services are independent.

Choose **Manual: choose provider and model** to reveal the provider and model selectors. A manual request is pinned to that exact model: failures and cooldowns are reported without silently changing providers. Models that accept screenshots are marked `(vision)`. Selection persists in this browser and survives world switches. Changing any selection cancels the old turn. Gemini, Groq and the curated AnyRouter free models are listed from the server's catalog; arbitrary model IDs and provider URLs cannot be submitted. Fully local and the existing local-vision/Groq Hybrid remain separate choices.

Auto uses the server-side `GEMINI_API_KEY`, `GROQ_API_KEY` and `ANYROUTER_API_KEY` from the ignored `.env.local`. AnyRouter also loads the existing key from `AI-TEST/.env.local` if no root override is configured. Keys are never sent to the browser. Auto prefers Gemini Flash-Lite models, then the other eligible Gemini Flash models, then Groq Qwen/GPT-OSS, then AnyRouter free models. Only providers with a configured key are attempted. Gemini/Groq model lists can be overridden using comma-separated `NPC_GEMINI_MODELS` and `NPC_GROQ_MODELS`; use chat models supported by your account, with structured output support. Defaults are listed in `server/cloud-pool.ts` and were checked against the accounts' model catalogs.

AnyRouter's curated choices are MiniMax M3.1 Flash for contextual action planning and chat, Nemotron 3.5 Lightning 30B A3B as a conversation fallback, and Nemotron 3.5 Super VL 120B A12B for visual questions. All use `:free` IDs plus `provider.max_price` set to zero for both input and output. No BYOK route, key donation, subscription or credit purchase is configured. A `$0` catalog headline alone does not mean all routes are free. The free MiniMax route did not advertise image support when checked, so it is treated as text-only even though other routes for that model accept images. Embedding, translation-only and device-only models are excluded. Slower options such as LongCat/Muse are omitted from the default pool for this latency-sensitive NPC.

Each model is attempted at most once per turn. Rate-limited, unavailable, timed-out, disconnected or invalid-response models enter a cooldown. Subsequent turns skip them and reconsider them after the cooldown. HTTP Retry-After and Gemini RetryInfo hints take priority. Unspecified transient failures back off from 15 seconds to five minutes; missing models and provider authorization/billing failures wait a day, and rejected request configurations wait an hour. A provider-wide access failure skips that provider's other models too. AnyRouter free-model 429s cool all its models because the account limit is shared. Cooldowns live in server memory and reset on a server restart. Auto uses 4.5-second Gemini/Groq attempt timeouts, eight seconds for AnyRouter, a 28-second total budget, and nine-second stall budgets per earlier provider to reserve time for later providers. Manual mode waits up to ten seconds for the pinned model. No endless retry loop runs in the background.

Short replies are buffered and validated before the game receives them. This allows a malformed or interrupted reply to fail over without displaying partial speech or executing a duplicate action. Action plans must name real world objects and supported interactions. AnyRouter uses a constrained `npc_reply` tool result for action turns; Gemini/Groq use structured JSON. Screenshots go directly to compatible cloud models; text-only models are skipped on image turns. Ordinary chat omits unnecessary pixels. Auto does not invoke the local LLM. Hybrid remains available for local vision with Groq conversation; Fully local stays independent of all cloud providers.

The usage HUD shows the active model, attempts/tokens for this server session, last reply latency and ready/cooling model counts. The pause menu adds each model's cooldown and reason. Groq quotas are the last upstream header snapshot, not a billing ledger; Gemini does not report remaining requests. AnyRouter shows its reported tier and free-trial remaining count when supplied, otherwise labels remaining allowance unknown. Failed attempts can also consume quota. Background deliberation is spaced at least 45 seconds apart in cloud mode.

Switching models cannot create unlimited free requests: Gemini quotas can be shared at project level and Groq quotas at organization level. AnyRouter's free access depends on the account plan and is rate limited across free models; Free accounts have a small one-time trial. If every eligible model is exhausted, Auto reports unavailable and waits for cooldowns; it does not enable paid service or silently fall back to local conversation. Rate-limit behavior is covered with simulated failures instead of deliberately exhausting the account.

References: [Gemini limits](https://ai.google.dev/gemini-api/docs/rate-limits), [Groq limits](https://console.groq.com/docs/rate-limits), [AnyRouter free access](https://www.anyrouter.dev/docs/features/free-tier), [AnyRouter routing](https://www.anyrouter.dev/docs/guides/provider-routing).
