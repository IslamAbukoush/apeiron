# Lore-driven fantasy RPG design package

- `Fantasy_RPG_Game_Plan.pdf` - the complete printable design and implementation plan.
- `Fantasy_RPG_Game_Plan.html` - editable source, with diagrams and linked references.
- `Build-GamePlan.ps1` - reproducible local PDF export using an installed Chromium browser.

Prepared on 10 November 2026. The document records confirmed preferences and clearly labels proposed scope, estimates, and hardware-dependent targets. This package contains planning documents, not an implemented game.
